# RASTA MUSIC EXTRACTOR AI

Cloud-based AI audio separation platform.

## Main Features
- Vocal Remover
- Instrumental Maker
- 4-Stem Separation
- MP3 and WAV Processing
- Lyrics Transcription
- AI Music Style Prompt Generator

## Architecture
- Android application frontend
- Python FastAPI cloud backend
- AI audio separation engine based on UVR
